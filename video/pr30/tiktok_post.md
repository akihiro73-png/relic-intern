# TikTok 投稿メモ（Scrollish PR動画）

## 使う動画

| ファイル | 使いどころ |
| --- | --- |
| `scrollish_pr30.mp4` | 合成BGM入り。そのまま投稿するならこちら |
| `scrollish_pr30_sfx_only.mp4` | 効果音（ドン・キラーン）だけ。TikTok の楽曲を重ねるならこちら（おすすめ） |

## キャプション案

```
気づいたら1時間スクロールしてる人へ📱
どうせ見るなら、TOEICに出る英語が流れてくるほうにしない？

「牛乳」ってコメントしてね🥛
アプリはプロフィールのリンクから試せます

#TOEIC #TOEIC初心者 #英語 #英単語 #スキマ時間 #大学生 #社会人 #Scrollish
```

## 投稿前にやること

1. プロフィールのリンク欄に Vercel の公開URLを入れる（リンクを置けない場合は、プロフィール文にURLを書く）
2. 楽曲を付ける場合は `_sfx_only` 版を使い、楽曲の音量は控えめにする（効果音が聞こえる程度）
3. 投稿後、反応を見る指標：いいね・保存・コメント数（「牛乳」コメント）・プロフィールへのアクセス・リンクのクリック
