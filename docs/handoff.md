# Scrollish 引き継ぎメモ（Claude Code 用）

元チャット：「新規事業の壁打ち：アプリ案の検証」「クリエイティブ作成の進行」（2026-11-14）

表記ルール：【決定】＝ユーザーが決めたこと／【提案】＝Claudeが提案し、ユーザーが明示的には確定していないこと

## 1. 経緯

- 最初は『7つの習慣』ベースの週間スケジュールアプリ「RoleWeek（仮）」を壁打ちしていた（TOEIC初級者向けに絞り、競合調査まで実施）。
- 途中でユーザーが方針転換し、RoleWeekを置き換える新案として「SNSのような英語の縦型ショート動画プラットフォーム」を作ることになった【決定】。RoleWeekで決めた事項（教材を作らない、5〜10人で4週間検証、継続は週単位で測る）は、新案ではいったん白紙扱い。
- 名前「Scrollish（スクロリッシュ）」、画面構成、8つの動画形式、配色は【提案】として出したもの。ユーザーは「そのプロンプトから作って」と進めたので、現時点の前提として扱ってよい。

## 2. 決まったこと

### プロダクト

- 対象ユーザー【決定】：TikTok・リールなどの縦型ショート動画をつい見続けてしまう人。ペルソナはユーザー本人（夜22〜24時、朝起きて1時間、電車の中など、1日3時間以上）。PR動画のターゲットは「TOEICを始めたばかりでスコア低めの大学生・社会人。場面は限定しない」。
- 課題【決定】：ショート動画を見ている時間が、英語の勉強にまったくなっていない。
- 解決策【決定】：英語の簡単な縦型動画が流れるSNSで、いつもと同じように楽しく見ているだけで勉強できる状態にする。
- ゴールの捉え方【決定】：英語力の数値目標は置かない。「いつものSNSの時間を、英語の縦型動画SNSの時間に置き換えられたか」で見る。
- 検証したいこと【決定】：面白さ・見続けやすさ（英語の簡単な縦型動画でも、TikTokと同じように止まらず見続けてもらえるか）。
- 合格ライン（何本・何分見たら合格か）は未決定。ユーザーは「わからないからプロダクトを作って」と判断し、アプリ側では記録だけ取る方針。

### PR動画（Scrollish自体の宣伝動画）

- 目的：ユーザー獲得ではなく、どの価値が刺さるかを探るテストマーケティング。
- 提供価値【決定】：「TikTokを見るよりは全然マシで、ためになった」と感じられること。「ためになった」の中身は「TOEICに出る表現だとわかった」。
- 導線【決定】：いいね・フォロー・コメント。コメントのお題はユーザー案が「朝ご飯派か夜ご飯派か」、Claude案が「スクロールするのは朝派？夜派？」（どちらにするか未確定）。
- 動画の制作はClaudeで行い、画像素材はChatGPTで作る【決定】。

## 3. アプリ要件（scrollish_prompt.md の要点）

**技術スタック**：Vite + React + TypeScript、Tailwind CSS、shadcn/ui（Button／Card／Dialog／Toast を `src/components/ui` に）、lucide-react、react-router-dom、date-fns。スワイプはCSSの縦 scroll-snap、IntersectionObserver で表示中の動画を判定。

**作る範囲**：バックエンドなし。localStorage に保存し、リロードや翌日でも消えないようにする。ログイン、ユーザー投稿、コメント、フォロー、通知、AIおすすめは作らない。並び順は「形式をランダムに混ぜ、同じ形式は2本連続にしない」。

**動画の表現**：本物の動画は使わない。CSSアニメーション、グラデーション背景、絵文字、大きな文字で「動画っぽいカード」にする。英語音声は Web Speech API（en-US）、効果音（ドン／キラーン／ブブー／シャッ）は Web Audio API でその場で生成。自動再生制限のため初回だけ「タップして音をON」画面を出す。

**ベンチマーク（TikTok／リール）から取り入れる要素**：全画面縦型の無限フィード、冒頭1〜2秒のフック、画面中央の大きな焼き付け字幕、8〜20秒のループ、右側のいいね／保存（＝単語帳）／シェアと数字、ランダムな形式とたまに出る金色の「レア動画」、アンケート風の2択、下部の進捗バー、架空の投稿者アカウント（@dopa_eigo、@toeic_neko、@native_bro など）。

**動画形式（各5本、計40本）**：言えるかな／教科書vsネイティブ／1単語ドカン／2択クイズ／あるある英語／ランキングTOP3／カタカナ英語チェック／カラオケ字幕。

### データ設計（後でSupabaseに移す前提）

- 型は `src/types.ts`。サンプル40本は `src/data/clips.ts`。
- `Clip`：id, type, creator, hook, en, ja, choices?, answer?, emoji, theme, is_rare, duration_sec
- `Session`：id(uuid), user_id(string|null), started_at, ended_at, clips_viewed, total_ms
- `ViewEvent`：id(uuid), session_id, clip_id, started_at, watched_ms, completed, answered('correct'|'wrong'|null)
- `Reaction`：clip_id, liked, saved, updated_at（clip_idごとに1件、押し直しで上書き）
- 保存処理は `src/lib/repository.ts` に集約し、画面から localStorage を直接触らない。公開する非同期関数：`listClips` / `startSession` / `endSession` / `recordView` / `setReaction` / `listSaved` / `getTodayStats` / `listSessions`
- `visibilitychange` と `pagehide` でもセッションを終了・記録する。

### 画面

- `/` フィード：上下スワイプ、自動再生、タップで一時停止、右側ボタンは44px以上、上部に「今日 23本」カウンター（「勉強・学習・宿題」という言葉は画面に出さない）、10本ごとにまれに「今日ふれた英語 ○フレーズ」のご褒美カード、シェアは `navigator.share`、非対応ならリンクコピー＋トースト。
- `/saved` 保存した英語：英文と訳の一覧、タップでフィードと同じ見た目で再生、0件時は「気になった英語は右の🔖で保存できるよ」。
- `/lab` 検証用（ユーザーには導線を出さない）：セッションごとの本数・時間・離脱した形式、形式ごとの平均視聴時間と完走率、JSONダウンロード。

**デザイン**：背景 #0E0E10、ネオンピンク #FF3D7F、ネオンイエロー #F5E663、シアン #2EE6D6、レアは金 #FFC83D。フォントは Dela Gothic One（フック・字幕）、M PLUS Rounded 1c（本文）、Montserrat（英文）。375px基準、PC・タブレットでは中央に9:16。文言は日本語、説教せずノリよく軽い口調。

**仕上げ**：初回から40本見られる状態に。README にページ構成、ファイル構成、Supabase移行時に差し替えるファイル、/lab の見方を書く。

## 4. 既存コード（scrollish.jsx）

壁打ちチャットで、上の要件をもとに claude.ai のアーティファクト用に1ファイルのReactで作ったプロトタイプがある → **`prototype/scrollish.jsx` に保存済み**。

- 構成：デザイントークン `C` と背景 `THEMES`、投稿者 `CREATORS`、形式メタ `TYPE_META`、40本のデータ `RAW`→`CLIPS`、形式ごとのタイムライン `getBeats()`（何ms目にどの段階・効果音・読み上げを出すか）、効果音 `sfx()`、読み上げ `say()`、カード `Slide` と中身 `Content`、フィード生成 `useFeedGenerator()`（同形式の連続回避、10本ごとにご褒美カード）、`App`、検証画面 `Lab`。
- 保存は claude.ai 専用の `window.storage`（キー `scrollish:data`）を使っている。本番の Vite 版では localStorage + repository.ts に置き換える必要がある。
- 画面遷移は state 切り替えで代用（react-router 未使用）、shadcn/ui 未使用、TypeScript ではなく JSX。
- `/lab` は「今日 ○本」を2秒以内に5回タップで開く仮実装。
- 後から入れた修正：フィードを常にマウントしたまま保存画面・lab画面を z-30 で上に重ねる形にし、`view === "feed"` のときだけ再生するように変更。esbuild で構文チェック済み。

## 5. 画像素材（ChatGPT 用プロンプト、作成済み）

- `scrollish_image_prompt.md`：投稿者キャラ6人×表情5種（透明PNG）、背景10枚、単語イラスト22個、演出素材。画像に文字を入れない、見本2枚でOKをもらってから量産。命名は `chr_{キャラ}_{表情}.png`、`bg_{場所}.png`、`word_{単語}.png`、`fx_{名前}.png`。
- 見本2枚（`bg_bedroom_night.png`、`chr_neko_surprised.png`、941×1672）はチェック済み → `assets/images/` に保存済み。直す点は、背景上端の約20pxの透明帯、スマホの光が右下（UIと重なる位置）にあること、猫の「おどろき」が驚き顔に見えないこと。猫の横の黄色い「！」を残すかはユーザー判断待ち。ユーザーは「これは一旦いい」として次へ進んだ。
- `scrollish_image_prompt_2.md`：プロフィール画像7枚、サムネ16枚（8形式×2）、Instagramハイライト表紙6枚、app_icon、og_share、profile_header。命名は `pf_`／`thumb_{形式}_{連番2桁}`／`hl_`。
- ※ `scrollish_image_prompt.md` / `scrollish_image_prompt_2.md` 本体はまだこのリポジトリに無い。
